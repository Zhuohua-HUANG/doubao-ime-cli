安装内容

安装后会写入：

  • /usr/local/bin/doubao-voice
  • /usr/local/bin/doubao-voice-authorize
  • /Applications/DoubaoVoiceCLI.app
  • /usr/local/share/doubao-ime-cli/docs/

首次授权

macOS 不允许安装包静默授予辅助功能权限。安装完成后，请在“系统设置 > 隐私与安全性 > 辅助功能”里允许“豆包 Voice CLI”。

安装完成后也可以点击右上角麦克风图标，打开设置并复制给 Agent 的 CLI 使用说明。

你也可以稍后运行 doubao-voice-authorize 重新打开授权引导。
