Installed Files

The installer writes:

  • /usr/local/bin/doubao-voice
  • /usr/local/bin/doubao-voice-authorize
  • /Applications/DoubaoVoiceCLI.app
  • /usr/local/share/doubao-ime-cli/docs/

First Authorization

macOS does not allow an installer to silently grant Accessibility permission. After installation, allow "Doubao Voice CLI" in System Settings > Privacy & Security > Accessibility.

You can also click the microphone icon in the menu bar to configure shortcuts and copy Agent-ready CLI instructions.

You can run doubao-voice-authorize later to reopen the authorization guide.
